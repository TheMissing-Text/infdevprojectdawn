# Minecraft: Project Dawn

Minecraft: Project Dawn is the Quality of Life mod for the Infdev. It exploring the scenario what if Infdev era of development was really infinite, adding later features as well as adding new.

## Requitements and Compabilities 

 **Requitements** 
 Now mod come with two releases, one for the MultiMC/Prism Launcher instances and the other is for Betacraft.
 For MultiMC and Prism Launcher you need install normal release and use Alpha 1.0.4. Also you need the Paulscode fix or BetterJSON for the sound engine fixes
 For Betacraft you need install the infdev version of release and use inf-20100630-1340 
 
 **Compabilities** — unknown, because editing a lot of the classes
